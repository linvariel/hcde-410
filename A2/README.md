# A2 — Exploring sources of bias in data 

**Dataset:** Wikipedia Talk Corpus

**Source:** [Wikipedia Talk - Figshare](https://figshare.com/projects/Wikipedia_Talk/16731) 

**License / terms of use:** [Wikimedia Open License Policy](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_Open_Access_Policy)

## Questions I asked
- **What are the distributions of annotator demographics (gender, first language English, age group, and education level)?** 
- **Are there missing values, and how might missing values, not removing duplicates, and annotator demographics introduce bias in the data?** 
- **What is the significance of bias in the data if used as a training dataset for a general hostile speech detector?** 
- **What biases could arise from the labeling methods?**
